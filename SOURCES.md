# Sources et pièces de travail

Les identifiants S001–S057 désignent les sources du registre interne du 20 octobre 2026. Les notices ci-dessous permettent de distinguer une source historique conservée, une donnée distribuée et une publication externe. Une date de rapport interne n’est pas une preuve de priorité sur d’autres solveurs.

Les pièces brutes du corpus privé ne sont pas publiées avec cette édition. Les fiches en donnent une synthèse attribuée ; les calculs réellement distribués sont recensés dans [REPRODUCTION.md](REPRODUCTION.md). Les empreintes identifient les sources conservées et ne remplacent pas leur consultation.

## Références publiques consultées

- **EXT-ZZNIBLE — ZzNible** : [Cicada 3301 / Liber Primus — Reproducible Research Findings](https://github.com/ZzNible/cicada3301-liber-primus-findings/blob/main/README.md). README intégral consulté via GitHub ; attribution au pseudonyme du dépôt, sans certification du tout premier auteur du signal.

- **EXT-DUKOTAH — Dukotah et contributeurs du dépôt** : [Liber Primus — Findings](https://github.com/Dukotah/cicada3301/blob/master/liber-primus/docs/FINDINGS.md). 75 premières lignes consultées via GitHub ; crédit du dépôt et de ses propres campagnes, sans adoption de ses exclusions générales.

- **EXT-CICADASOLVERS — Communauté CicadaSolvers ; auteurs individuels à préciser** : [Liber Primus Cryptanalysis Briefing / QuickStart](https://www.cicadasolvers.com/quickstart/). Texte public consulté. Source communautaire de référence, pas preuve de la première découverte de chaque résultat.

- **EXT-G032 — Communauté de solveurs, documentation réunie par CicadaSolvers** : [15.jpg Square](https://www.cicadasolvers.com/wiki/liber-primus/lp2/15-jpg/15-jpg-square/). Page et liste de renvois consultées ; les pages liées n’ont pas toutes été vérifiées. Auteur initial de la reconstruction non déterminé.

- **EXT-DJUBEI — Communauté de solveurs, documentation CicadaSolvers** : [Dis Legomenon](https://www.cicadasolvers.com/wiki/liber-primus/dis-legomenon/). La page décrit les deux occurrences de DJU–BEI ; auteur initial non déterminé.

- **EXT-TOR-V2 — Tor Project et contributeurs** : [Tor Rendezvous Specification, protocole v2 historique](https://torproject.gitlab.io/torspec/rend-spec-v2.html). Sections 1.3 et 1.5 : identifiant de 80 bits, SHA-1 de clé RSA et encodage Base32.
