# G032 : le parcours est calculable ; le geste de sortie reste ouvert

**Résultat :** le même parcours permet de prélever des éléments ou de les déposer. Ces gestes inverses produisent des sorties différentes. Le T documenté dans les SPECIAL est obtenu par dépôt.

![Recadrage documentaire de G032](../images/G032-recadrage.png)

Le nombre rouge 3299 est en case 6, en comptant les cases par lignes à partir de 1. Sous la recette déjà connue `abs(3301 - premier[index Fibonacci])`, les seize nombres donnent le parcours :

```text
6, 7, 11, 10, 9, 5, 1, 2, 3, 4, 8, 12, 16, 15, 14, 13
```

Les 15 déplacements sont orthogonaux entre voisins. La recette est historique dans le projet : ce rejeu n’est pas une découverte aveugle.

| Geste | Définition, indices de cases à partir de 1 | Résultat avec hhhcc | Classe 30 |
|---|---|---|---|
| Prélèvement | `sortie[k] = entree[P[k]]` | `2h6vn7o256dtvsfp` | 3 composantes |
| Dépôt puis lecture par lignes | `grille[P[k]] = entree[k]` | `hdnv2o26765tvsfp` | T connecté |

Le T ne peut donc pas servir de preuve du prélèvement. Le lecteur RIGHT/RIGHT retrouve ses contrôles historiques avec le prélèvement ; ces contrôles rétrospectifs n’imposent pas le geste d’export.

Le retrait des trois bits constants transforme `hhh111cc` en `hhhcc`. Par exemple `126 = 01111110` donne `01110 = 14`. Cela prouve une opération exacte sous cette convention, pas une instruction de l’auteur. Le codage concurrent `cchhh` demeure documenté.

**Statuts :** calculs et différence dépôt/prélèvement SUPPORTÉS par reproduction ; choix final du geste INCONCLUSIF ; identification d’une destination Tor HYPOTHÈSE dans ce périmètre. Les recherches ultérieures sont intégrées dans la [mise à jour AUTH](2026-10-22-auth.md).

Le raccord du titre `149 + 489 = 638`, puis `638 mod 256 = 126`, est un INDICE FAIBLE exploratoire relevé après inspection. Il ne constitue pas une confirmation indépendante.
