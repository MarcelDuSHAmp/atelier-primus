# SRC-001 — Repère global G000–G074

Un seul numéro de page pour se repérer sans confondre les deux ensembles.

> Fiche historique du registre du 20 octobre. Les corrections et la synthèse actuelle priment sur ce statut ancien.

| Champ | Valeur |
|---|---|

| Nature | CONVENTION |
| Pages / objet | G000–G074 |
| Date de la source | 2026-10-20 |
| Reproduction historique | Documenté, non rejoué dans ce registre |

## Calcul ou observation

G000–G016 : premier ensemble ; G017–G074 : second. LP2 locale p = G−17. G032 est p 15 du second ensemble, pas G015.

## Ce que cela ne démontre pas

Le numéro G est notre repère ; le traiter comme adresse intentionnelle est une autre hypothèse.
